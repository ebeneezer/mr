 MR HELP - TABLE OF CONTENTS

American Cybernetics (makers of Multi-Edit) went out of business in 2020 and stopped development of the TUI version of Multi-Edit years bevor.

Mr is a rewrite of the classic programmers editor Multi-Edit by American Cybernetics for Linux terminals. It is constructed aroud a macro language processor, that compiles macro files based on the MEMAC script language. 
Now called MRMAC the language is backwards code compatible towards the MEMAC dialect but renewed and extended for modern systems. 
Compilation happens in-RAM through the MRMAC compiler that supports both precompiled and on-demand compiled macro files for maximum speed. 

Dependencies:
  - the Turbo Visison C++ rewrite TVISION from magiblot on GitHub. TVISION can also be steered from mrmac macros - just like it was in the old days with Multi-Edit
  - advanced data processing models like piecetables, addbuffers, tries and more to edit files larger than system memory and provide file I/O with blazing speed: It loads 1 GB text und under one single second und indexes the whole text in under 800 milliseconds (no BS)
  - a build in coprocessor for handling mrmac bytecode macros that can manipulate text in parallel to the user in the same window (no BS). The coprocessor supports running multiple macro jobs in parallel in different windows or multiple macrojobs in one window or both at the same time. Thecoprocessor uses multiple computes lanes in parallel: I/O, COMPUTE, MACRO and MINIMAP
  - ncursesw and is UTF8 capable

Features (among others):
  - automated syntax highlighting, code folding and smart indenting for all known programming languages (except the marsian X!/&%/:-P language)
  - a macro manager for recording macros and binding them to hotkeys. You can also create, manage, edit and bind .mrmac files from inside the manager
  - virtual desktops
  - workspaces: Loading, saving, autoloading,autosaving, workspace-wide multifile search & replace.
  - a window manager that can tile, minimize and cascade windows
  - recursive multi file search & search and replace
  - full Perl regex PCRE2
  - a sub character minimap display
  - inter window copy & paste and copy & paste with the OS
  - stream block, line blocks and colum blocks including sorting of the marked block
  - an key mapping manager and loadable key mapping to emulate other stateless editors like Emacs, Nano or Wordstar
  - profiles per file extension or group of file extensions: You can setup the handling of code files depending of the code you edit
  - color theme loading and saving from file extension profiles
  - automatic language detection
  - automatic multi-level graphical code folding
  - smart indenting and undenting
  - printing via PDF exports
  - acquire files from the output of shell commands or pipes
  - compiler profiles with automatic setup and error tracking in code
  - hex edit mode with synchonous hex, dec, oct, strings and binary view plus additional data inspector

.topic MenuFile=10
 FILE MENU

Open loads a file in a new editor window.  Load replaces the contents of the
current suitable editor window.  Get last lists recently used files, folders,
and workspaces.  Acquire scans a directory or runs a command and presents the
resulting files for selection.

Open live log follows a text file as it grows.  Open journal reads systemd
journal output, optionally filtered by application tag.  Open workspace
loads an MR workspace description.

Save writes the current document.  Save as selects another URI.  Save all
offers to write all modified documents.  Info displays document, file, and
editor metadata.  Export to PDF opens the PDF export settings.  Exit closes
MR after dirty documents and settings have been handled.

Related dialogs: {Get Last:DialogGetLast}, {Acquire:DialogAcquire},
{File Information:DialogFileInformation}, {PDF Export:DialogPdfExport}.

.topic MenuEdit=11
 EDIT MENU

Undo and Redo traverse the editor's change history.

Mark all selects the complete document.  Cut removes the selection and puts
it in the editor buffer.  Copy leaves the source unchanged.  Append adds the
selection to the existing buffer.  Cut and append combines removal with
append.  Paste inserts the current buffer.

Insert toggles insert and overwrite mode.  The displayed ON or OFF state is
the state that will be used for subsequent text entry.

.topic MenuWindow=12
 WINDOW MENU

Open creates another editor window.  Close closes the active window.  List
opens the complete window and workspace control dialog.

Next and Previous select neighboring desktop windows.  Hide removes a window
from normal selection without closing it.  Zoom toggles maximized geometry.
Minimize/restore changes between the normal window and its one-line desktop
representation.

Organize contains tiling, cascading, split, and virtual-desktop operations.
Link and Unlink control the MRMAC window link used by editor procedures.

See {Organize submenu:MenuWindowOrganize} and {Window List:DialogWindowList}.

.topic MenuWindowOrganize=13
 WINDOW - ORGANIZE SUBMENU

Cascade overlaps ordinary desktop windows.  Tile partitions the usable
desktop among them.  Split window horizontal or vertical creates another
viewport of the same supported document.

Move viewport right or left changes the visible virtual desktop.  Move window
to right or left desktop changes the active window's membership and then
selects the target desktop.

These operations apply only to TVision-managed desktop windows.  Modal
dialogs and the Help window do not participate.

.topic MenuBlock=14
 BLOCK MENU

Copy, Move, and Delete operate on the marked block.  Load block reads text
from disk into the block position; Save block writes only the marked block.
Indent and Undent adjust the selected lines by the configured indentation.

Window copy and Window move transfer a block between editor windows.

Mark lines selects complete lines, Mark columns selects a rectangle, and Mark
stream selects a continuous character range.  Hide/show block mark changes
only the projection.  End marking completes the current mark.  Turn marking
off removes it.

Persistent blocks controls whether a completed block survives cursor movement.
The ON or OFF suffix reports the current runtime setting.

.topic MenuSearch=15
 SEARCH MENU

Search for text opens the single-document search form.  Search and replace
adds replacement text and replacement policy.  Repeat previous search uses
the last accepted search specification without reopening the form.

Multiple file search scans the selected file set.  List files from last
search reopens the previous result set.  Multiple file search and replace
adds controlled replacement and per-hit review.

Push position stores the current location on the marker stack.  Get position
returns to the most recently stored valid location.  Goto line number moves
to a one-based document line.

Related dialogs: {Search:DialogSearch}, {Search and Replace:DialogSearchReplace},
{Multiple File Search:DialogMultiFileSearch}, and {Goto Line:DialogGotoLine}.

.topic MenuText=16
 TEXT MENU

Push and Get position expose the same marker-stack operations as Search.
Line drawing changes typed line characters; Double lines selects the double
line set.  Hex editor opens the current file in the Bento hex editor.

Upper case and Lower case transform the selected block or applicable text.
Center line uses the configured margins.  Re-format paragraph wraps the
current paragraph.  Re-format code invokes the configured language formatter.

File compare opens a compare view.  Apply original to compare and Apply
compare to original transfer the currently selected difference in the named
direction.

.topic MenuOther=17
 OTHER MENU

Installation and setup contains color, keymap, filename-extension, compiler,
path, backup, user-interface, and live-log configuration.

Build current file chooses the matching compiler profile and starts its build
pipeline.  Git changes presents repository changes.  Stop current program and
Restart current program control the active run session.  Clear current output
clears the associated output view.

Next and previous compiler error navigate the current build diagnostics.
Match parenthesis moves between matching brackets or parentheses.

See {Installation and Setup:MenuInstallationSetup}.

.topic MenuInstallationSetup=18
 INSTALLATION AND SETUP SUBMENU

Color setup edits palette groups and theme files.  Key mapping edits profiles
and bindings.  Filename extensions associates language and editor behavior
with file patterns.  Compiler profiles describes toolchains and build hooks.

Paths selects settings, macro, Help, temporary, shell, and log locations.
Backups / Autosave configures backup and workspace safety behavior.  User

projection.  Live logs controls result messages, sounds, and log viewers.

Every setup dialog has its own Help page explaining each field.

.topic MenuMacro=19
 MACRO MENU

Macro Library lists available macro files, definitions, bindings, and
AUTOEXEC membership.  Playback runs the selected macro normally; Debug starts
it in the macro debugger.

Recording start/stop captures eligible key activity into a new macro source.
When recording stops, MR offers a key binding for the recorded macro.

Runtime-created macro menu groups are explained in
{Runtime Macro Menus:MenuRuntimeMacro}.

.topic MenuHelp=20
 HELP MENU

Table of contents opens the main Help page.  Keys opens the keyboard reference.
Detailed index opens an alphabetical subject index.  Previous topic returns

Performance panel toggles the runtime scheduling and coprocessor diagnostic
panel.  About displays build and product information.

F1 is context-sensitive.  Shift-F1 opens the index and Alt-F1 opens the
previous topic.

.topic MenuRuntimeMacro=21
 RUNTIME MACRO MENUS

MRMAC code may add menu groups and commands at runtime.  Their labels and
behavior are defined by the owning macro, not by the compiled MR command set.
The macro file is therefore the authority for command-specific semantics.

Selecting a runtime item executes its registered macro specification.  Help
for creating such entries belongs to the MRMAC reference manual.

.topic DialogGetLast=100
 GET LAST DIALOG

Files lists recently opened or saved document URIs.  Folders lists recent
directory locations.  Workspaces lists recent workspace files.  Empty groups

.topic DialogMacroBindCapture=101
 BIND RECORDED MACRO KEY

Press the key or modified key combination that shall invoke the recorded
macro.  Esc leaves the macro unbound.  Alt-F10 is ignored here so that the

.topic DialogJournalTag=102
 OPEN JOURNAL DIALOG

App tag is the systemd journal identifier used to filter the opened stream.
The history control offers previously accepted tags.  Journal identifiers

Choose an identifier or type a tag and select OK.  An empty tag opens the
unfiltered journal command configured by MR.

.topic DialogFoundList=103
 FOUND LIST DIALOG

The list contains matches from the most recent search operation.  Each row
identifies the matching document and location.  Activate a row to load or
focus its document at the match.  Done closes the list; Cancel abandons the
current list interaction.

.topic DialogReplacePrompt=104
 REPLACE CONFIRMATION

Replace changes the current match.  Skip leaves this match unchanged and
continues.  Replace All applies the accepted replacement policy to all
remaining matches.  Cancel stops replacement.

The surrounding lines are a preview, not an editable buffer.

.topic DialogSearchContinue=105
 SEARCH CONTINUATION

Next continues the search from the current boundary.  Stop keeps the current
position and terminates this search.  Cancel abandons the continuation
request.

.topic DialogSearch=106
 SEARCH DIALOG

Search text is the literal or pattern to locate.  Case sensitivity, whole
word/phrase, PCRE, and direction controls determine how it is interpreted.
Mode selects stop on first, prompt for next, or list all.  Global search,
marked-block restriction, and all-windows search determine traversal scope.

Go starts the operation with the displayed settings.  Cancel leaves the
previous accepted search specification unchanged.

.topic DialogSearchReplace=107
 SEARCH AND REPLACE DIALOG

Search text identifies matches.  Replacement text is inserted for an
accepted match; regular-expression replacement syntax is enabled only when
the corresponding search mode is active.

Type and direction use the Search dialog semantics.  Mode selects replace
first, prompt for each, or replace all.  Leave cursor at selects the start or
end of the accepted replacement.  Global, marked-block, and all-windows
options determine scope.  Go starts the operation.  Cancel preserves the
previous accepted search specification.

.topic DialogMultiFileSearch=108
 MULTIPLE FILE SEARCH

Filespec selects candidate names; an empty value becomes *.*.  Start at is
the search root.  Recursive search includes descendants.  Search names the
text or expression.  Case sensitive, regular expressions, and whole words
select matching rules; whole words takes precedence over regular expressions.

Search editor windows or search files in memory includes already loaded
documents.  Restrict to workspace limits candidates to the active workspace.
In replace mode, Keep all files open prevents processed files from being
closed after replacement.

Replace is the replacement text in replace mode.  Done submits the immutable
search request.  Results are collected in the background and later adopted
by the UI.

.topic DialogMultiFileResults=109
 MULTIPLE FILE SEARCH RESULTS

Each row represents one accepted result with file and location.  Load opens
the selected result; Load All opens all eligible result files.  In replace
review, Replace changes the selected hit, Replace All accepts the remaining
eligible hits, and Skip advances without changing the current hit.

.topic DialogGotoLine=110
 GOTO LINE NUMBER

.topic DialogLeftMargin=112
 SET LEFT MARGIN

.topic DialogCompilerProfiles=116
 COMPILER PROFILES

Profile ID is the stable settings key.  Name is the displayed name.  Toolchain
describes the compiler family.  Executable is the program URI.  Version and
Target constrain profile matching.  Build flags are passed to the build.

Pre build cmd runs before compilation.  Build succeeded cmd and Build failed
cmd run after the corresponding result.  Their audio fields name sound files.
Pre build macro and Post build macro name MRMAC files.  Includes, Libraries,
and Runtime carry toolchain-specific arguments.

Add creates a profile, Copy duplicates the selected profile, Delete removes
it, and Automatic Setup probes supported local compilers.

.topic DialogFileExtensions=125
 FILENAME EXTENSIONS

Profiles selects a filename-extension profile.  Profile ID is its stable key;

.topic DialogPaths=126
 PATHS

Settings macro URI is the canonical settings.mrmac location.  Macro directory
contains indexed MRMAC sources.  Help file URI names the compiled TVision
mr.hlp file.  Temporary directory holds disposable working files.

Shell executable URI is the program used for shell commands.  Audio player URI
is the executable used for audible signals.  Logfile URI is enabled when Log
to file is selected and names the persistent MR log destination.

Path history, File history, and Workspace history are the retained entry
counts, each from 5 through 50.  Log handling selects a volatile in-memory log,
the named file, or journalctl.  Browse buttons select a file or directory for
the corresponding field.

Paths may be absolute or accepted normalized inputs.  Applying this dialog
updates the central runtime settings model; it never writes settings directly.

.topic DialogBackups=127
 BACKUPS AND AUTOSAVE

Backup method selects Off, create Backup file, or move to backup Path.  Backup
frequency selects First save only or Every save.  Backup file ext. is used by
the backup-file method.  Backup path is enabled by the move-to-path method.

Keyboard inactivity starts autosave after 5 through 100 idle seconds.
Intervall auto save starts it every 100 through 300 seconds.  Zero disables
the respective trigger.  The sliders and labels display seconds.
