\begin{abstract}
This compact document is intended to demonstrate a local outline view for
LaTeX in the single editor.  It contains numbered sections, starred sections,
optional section titles and common environments.
\end{abstract}

\section{Introduction}

The outline should show the document environment and the structural commands
below this point.  Plain paragraphs should not create outline noise.

\subsection{Motivation}

The user needs a navigable structure list for LaTeX document structure.

\subsection*{Unnumbered Background}

Starred headings are useful in real documents and should still be navigable
when the local outline can identify them safely.

The proposed single-editor action would show the same local outline snapshot
that Bento already uses, then jump to the selected source offset.

\section{Results}

\begin{itemize}
  \item One entry should be executed directly.
  \item Multiple entries should be shown as a navigation list.
  \item Empty outline should produce a status message, not a dead menu item.
\end{itemize}
